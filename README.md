# FinSight

A modern personal finance and analytics dashboard built with React.

## Overview

FinSight helps users track income, expenses, budgets and financial goals through a clean and responsive dashboard.

The application focuses on a simple user experience while providing useful financial insights through interactive charts.

## Features

- Personal finance dashboard
- Income and expense tracking
- Add transactions
- Edit transactions
- Delete transactions
- Search transactions
- Filter by transaction type
- Spending category analysis
- Monthly income vs expense analytics
- Budget tracking
- Financial goals
- CSV transaction export
- Dark mode
- LocalStorage persistence
- Responsive design

## Tech Stack

- React
- Vite
- JavaScript
- React Router
- Recharts
- Lucide React
- CSS
- LocalStorage
